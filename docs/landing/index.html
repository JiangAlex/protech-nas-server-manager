快速開始

3 分鐘啟動您的第一個專案

簡單幾步，即可開始使用 ProFlow

1

安裝 用戶端

使用 npm 或 yarn 快速安裝 ProFlow CLI 工具

# 使用 npm 安裝
npm install -g proflow-cli

# 或使用 yarn
yarn global add proflow-cli
2

初始化專案

在您的工作目錄執行初始化命令

proflow init my-first-project
cd my-first-project
3

啟動開發伺服器

一鍵啟動本機開發環境，即時預覽變更

proflow dev

# 輸出：
Ready on http://localhost:3000
